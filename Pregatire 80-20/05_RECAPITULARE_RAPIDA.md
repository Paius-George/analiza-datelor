|---|---|
| Mean 6,54; SD 3,13 pentru o rată | Media ratei este 6,54%; SD este 3,13 puncte procentuale |
| Histogramă cu coadă spre dreapta | Asimetrie pozitivă; câteva valori ridicate |
| Punct separat în boxplot | Valoare potențial atipică, fără eliminare automată |

| Loading | Coeficient, fără interpretare automată ca procent/corelație |

**Înainte să scrii:** ce sunt rândurile? Ce sunt coloanele? Ce axe văd? Ce codifică legenda?

**Nu confunda:** scor cu corelație; loading cu matrice factor; contribuție cu cos²; Dist cu Dist²; asociere cu efect cauzal; scor pozitiv cu situație favorabilă.
