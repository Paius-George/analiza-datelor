# Pregătire pentru parțial — de unde încep

Materiale pregătite pe baza celor trei seminarii și a cursului ACP. Outputurile numerice sunt fragmente din fișierele existente; simularea include și un set didactic diferit. Nu s-au executat scripturile de analiză R.

1. **01_GHID_OUTPUTURI.md** — recunoaștere, reguli, exemple și capcane pentru fiecare tip de output; include grafice.
2. **02_SIMULARE.md** — 60 minute, 9 exerciții de interpretare, 10 puncte cu punctul din oficiu.
3. **03_BAREM.md** — răspunsuri și punctaj de antrenament; se deschide după rezolvare.

Punctajul este un instrument de pregătire, nu baremul oficial al profesorului. Exemplele economice nu trebuie transferate mecanic la alți indicatori.

## Ordinea recomandată

- **Prima sesiune, 45–60 min:** tipuri de date, descriptive, histogramă, boxplot, corelație și standardizare. Explică două grafice cu voce tare.
- **A doua sesiune, 60 min:** summary, lambda, criterii de selecție, loadings, scoruri și matrice factor. Calculează manual trei valori.
- **A treia sesiune, 60 min:** Variables și Individuals, contribuții, cos², distanță. Explică de ce „contribuție mare” și „bine reprezentat” sunt diferite.
- **A patra sesiune, 45–60 min:** cerc, observații, biplot, axele 3–4 și grafice cu patru variabile. Citește întâi axele și legenda, nu interpretarea memorată.
- **A cincea sesiune, 60 min + corectare:** simularea fără fișă; recuperează punctual greșelile.

Dacă ai o singură zi: primele patru sesiuni pot fi comprimate în blocuri de 25–30 minute, cu pauze, apoi simularea. Dacă ai mai multe zile, distribuie sesiunile și revino a doua zi asupra greșelilor.

## Checklist înainte de test

Pot explica fără ajutor:

- [ ] ce sunt rândurile și coloanele fiecărui output;
- [ ] procent versus proporție; SD versus varianță;
- [ ] loading versus corelație versus scor;
- [ ] cum aleg axele din coloana cumulată;
- [ ] de ce Kaiser λ>1 este pentru ACP standardizată;
- [ ] ce înseamnă un semn negativ și de ce axele pot fi inversate;
- [ ] contribuție versus cos² și sumele corecte;
- [ ] Dist versus Dist²;
- [ ] cercul corelațiilor versus biplot;
- [ ] cum citesc un grafic pe PC3–PC4;
- [ ] de ce culoarea nu înseamnă automat performanță;
- [ ] ce nu pot deduce din output: cauzalitate, independență, semnificație sau asemănare completă.

## La fiecare răspuns

„Ce este?” → „Ce valori văd?” → „Ce înseamnă?” → „Ce acoperire are?” → „Ce limită trebuie precizată?”

Începe cu datele oferite de subiect. Dacă o informație lipsește, spune că nu se poate deduce din fragmentul disponibil.
